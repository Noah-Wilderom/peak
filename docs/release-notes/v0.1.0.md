First packaged release of Peak, a process monitor and memory profiler for development.

Capture a command or attach to a process, then watch memory, CPU, I/O, GC and heap contents live. Local monitoring runs on Linux, macOS and Windows. Remote targets (SSH, Docker, Kubernetes) are Linux machines. Installed copies find new releases on their own and ask before installing or restarting.

See the README for which capabilities each platform has.
