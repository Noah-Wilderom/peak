Profile Go, Bun and PHP programs from the inside, alongside Node.js and Python.

- **Go:** add one import, `github.com/Noah-Wilderom/peak/sdk/go/auto`, for heap, garbage collections, scheduler latency, CPU profiles and allocation profiles. It does nothing outside Peak.
- **Bun:** nothing to set up, on Bun 1.2.15 or newer. Heap, timer delay and heap snapshots, and CPU profiles from Bun 1.3.7.
- **PHP:** nothing to set up for figures at exit. Install the Excimer extension for live memory, collections and CPU profiles. Excimer has no Windows build, so Windows gets figures at exit.
- **The Profiler says what it's looking at:** the runtime and agent versions, what they measure, what they can't and why.
- **New commands:** `peak ps`, `peak profile`, `peak open` and `peak agents`.
- **Fixed:** `peak run` no longer replaces your own `NODE_OPTIONS` and `PYTHONPATH`, and `install.sh` names any desktop libraries a Linux machine is missing.

The README has the full table of what each runtime offers. Attaching to a running process still gives its OS-level monitoring: memory, CPU and I/O. Reading a runtime from the inside takes starting the program through Peak, and for Go, building it with the import.
